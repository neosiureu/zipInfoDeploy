# 카드 (만들기 설계안 8절)

일의 규칙을 적은 짧은 글이다. ①이 든 판은 `search_cards`·`read_card` 도구로 필요할 때 읽고, B0+는 전문을 시스템 글 뒤에 받는다.

- `v0/`: 연습 전 판이다. 5단계에 커밋하고(설계안 11절), 선택 판 B0+(연습 전 카드)의 입력이 된다. 연습(시운전)을 마치고 얼린 판은 새 폴더에 둔다.
- **꼴:** 카드마다 파일 하나(`K01.md`)다.
    - 첫 줄은 `# K01 제목`이다. 그다음 두 줄에 찾기용 영어 태그와 한글 낱말을 쉼표로 적는다.
    - 층은 셋이다: `## 핵심`(세 줄 안), `## 사용법`, `## 기록`(연습에서 더한 줄, 연습 전 판에서는 비어 있음).
    - 읽는 코드는 `zipinfo-project/ai-core`의 `com.zipinfo.ai.cards.Cards`다. 모델에게는 태그 줄과 빈 기록 층을 뺀 글이 간다.
- **찾기:** 영어 낱말은 카드의 영어 태그와 같으면(대소문자 무시), 한글 낱말은 카드의 낱말이 글 안에 있으면(빈칸 무시) 찾는다. `search_cards`와 ⓪(의도 잠금)이 같은 규칙을 쓴다. 차례는 카드 ID 순이다.
- **지키는 것**
    - 카드는 장치를 말하지 않는다. B0+가 같은 글을 프롬프트로 받기 때문이다.
    - 특정 매물이나 정답 값을 넣지 않는다.
    - 사고 과정을 적게 하는 말을 넣지 않는다(01 209줄).
    - K05(기간과 잠정)는 달 숫자 없이 쓴다. 끝 달은 `trade_stats` 설명의 덮는 달에서 나온다.
    - 하네스 시험 `CardsCheckTest`가 이것들을 본다.
- K10(금지 표현)의 "쓰지 않는 말"은 규칙 채점(설계안 9.4)의 금지 표현 목록과 같다.
