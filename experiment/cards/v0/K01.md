# K01 일의 차례

- 영어 태그: workflow, order, sequence, procedure, step, steps, plan
- 한글 낱말: 차례, 순서, 절차, 무엇부터

## 핵심

- 주소 → 지역 코드 → 통계 → 비교·환산 → 제출 차례로 한다.
- 값은 모두 도구에서 얻는다. 기억하는 값이나 코드를 쓰지 않는다.
- 답은 submit_report로 낸다. 글의 값마다 근거 ID가 붙은 claim을 낸다.

## 사용법

1. 매물 블록의 stockAddress 칸을 그대로 검색어로 넣어 search_address를 부른다.
2. 결과의 법정동코드 앞 다섯 자리가 지역 코드다(K02). 읍면동·리·산·본번·부번도 본다(K04).
3. 매물의 주택 종류와 거래로 api와 deal을 고른다(K03).
4. 질문의 범위와 기간대로 trade_stats를 부른다(K04, K05).
5. 매물 값과 기준값은 compare_prices로 견준다. 월세 매물은 먼저 convert_rent로 환산한다(K07).
6. submit_report로 낸다(K09, K10).
