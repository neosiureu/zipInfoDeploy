# K03 실거래 API 고르기

- 영어 태그: api, dataset, apartment, villa, rowhouse, officetel, sale, purchase, jeonse, housing, type
- 한글 낱말: 아파트, 연립, 다세대, 오피스텔, 매매, 전세, 실거래 자료, 주택 종류

## 핵심

- api는 주택 종류와 거래로 정한다. 아파트는 apt, 연립다세대는 rh, 오피스텔은 offi이고, 매매면 뒤에 _trade, 전세·월세면 _rent를 붙인다.
- deal에는 매물의 거래(매매·전세·월세)를 그대로 쓴다. _trade는 매매만, _rent는 전세·월세만 받는다.
- 전세와 월세는 같은 _rent 자료에서 월세가 0인지로 갈린다.

## 사용법

1. 매물 블록의 stockForm(주택 종류)과 stockType(거래)을 본다.
2. 예: 아파트 매매는 api apt_trade와 deal 매매, 오피스텔 월세는 api offi_rent와 deal 월세다.
